# Competitive Note — eToro (2026-08-17)

**Scope:** one-page competitive read on eToro vs IOST Terminal. Sources: etoro.com homepage (2026-07 build), eToro press releases "eToro Leverages AI to Redefine Social Investing" and "eToro Launches New App: AI-first, Smart, and Social", etoro.com/trading/platforms/tori.

---

## What eToro is

Social investing platform + regulated brokerage: 40M+ users, 75 countries, since 2007, Nasdaq-listed (ETOR), FINRA/SEC (US) + FCA (UK/EU) regulated, SIPC/FDIC protected, custody at J.P. Morgan / UBS / Citi. 5,000+ assets (stocks, crypto, ETFs), fractional shares from $10, $0 stock commissions, 1% flat crypto fee, $100K Virtual Portfolio practice mode, CopyTrader + social feed + Academy.

## Their 2026 AI push — validation of the IOST thesis

- **Tori** — AI companion: portfolio insights, market signals, natural-conversation guidance (also via WhatsApp / Apple Watch).
- **Agent-powered portfolios** — users build or copy AI agents that trade 24/7 in per-goal sub-accounts; humans stay in control and can pause/stop.
- **AI tools + API marketplace** — Popular Investors build algorithms, automated execution, backtesting, dashboards (VaR, stress testing).
- **Alpha portfolios** — strategies built on eToro's proprietary retail-trading data.
- Self-custody crypto wallets (Zengo), AI-first app, desktop "etoro edge".

The largest social-trading platform on earth is now telling its users the future is **AI agents trading with human oversight** — which is IOST Terminal's founding position, in their own words.

## Head-to-head

| Dimension | eToro | IOST Terminal |
|---|---|---|
| Core model | Human social copy-trading | AI-agent-native trading command center |
| AI agents | Feature bolted onto a brokerage | The product (autopilot, agent API, agent wallets) |
| Trust | Regulatory moat (FINRA/SEC/FCA), custody banks | On-chain: signals hash-pinned on IOST L1, provable track records |
| Agent economy | None — no token layer | AITT: trust staking (KYA), 20% fee burn (200M cap → 800M floor), DAO governance |
| Agent spend control | Agents trade inside a user sub-account | Economically enforced: stake → Trust Score → spend rails, slashing (Phase 2) |
| Settlement | Fiat rails, custodial | IOST L2, cheap, crypto-native; BSC bridge for liquidity (Phase 4) |
| Scale | 40M users, regulation, brand | Pre-launch, focused, nimble |

## Moats

**eToro's (hard to copy):** regulation + custody + 40M-user distribution + brand + mobile app + asset breadth.

**IOST's (hard for them to copy):**
1. **Provable on-chain trust** — agent track records verifiable by anyone, forever (their Alpha portfolios run on proprietary data).
2. **Token-incentivized agent economy** — trust staking, fee burns, DAO; eToro has no economic layer for agents.
3. **Economically-enforced spend authority** — stake-backed credit lines and slashing vs "customer support".

## Risk

eToro's distribution could mainstream "copy an AI agent" before AITT ships. The agentic-payments/trust layer is the differentiator and the window — ship quality over speed, but the thesis is now externally validated, not speculative.

## Cheap steals (adopt when relevant)

- "Practice today. Invest tomorrow." framing for the $100K paper portfolio.
- Per-goal sub-accounts — wallet structure already exists (`uw_*` / `aw_*`).
- "No hidden fees" transparency messaging — already free-by-design; say it boldly.
- Education layer (Academy) — trading-tutor already covers this; productize it.

## Takeaway

eToro = Goliath adding AI as a feature. IOST Terminal = AI-agent-native architecture adding rails. Compete on provable trust + token-incentivized agents, not on distribution.
