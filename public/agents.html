Connect in four deliberate steps

  1. Read the quick guide and authentication documentation. MCP endpoint: https://iostcallister.com/mcp.
  2. Have the owner use Launchpad to configure a bounded paper wallet, Pact and revocable key. Never paste credentials into a public prompt, URL or issue.
  3. Discover tools using the actual authenticated session. Inspect the returned input schemas and selected allowlist; do not assume tool names, counts or permissions from this page.
  4. Start with authorized read-only status checks. Any mutation needs its documented authorization and current evidence. A successful preflight is not owner approval.
